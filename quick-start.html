ESP32 Quick Start & Recovery

Use this page when the ESP32 is running WestTech ESP32 verification firmware. It walks through setup Wi-Fi, basic verification, optional firmware upload, and simple recovery steps if setup does not go as expected.

Important: This is for the WestTech ESP32 verification image. It is not the final GP/MP product firmware. GP/MP firmware is installed only when the customer ordered or needs the default firmware for that panel family.
Before You Start
Use the right Wi-Fi and power.

These items prevent most setup problems.

2.4 GHz Wi-Fi

Use a 2.4 GHz Wi-Fi network. ESP32 devices do not join 5 GHz-only Wi-Fi networks.

Stable USB power

Use a stable 5 V USB power source and a known-good USB cable.

Setup device

Have a phone, tablet, or laptop with Wi-Fi available.

Firmware file

If installing default firmware, have the correct GP/MP ESPHome firmware .bin file ready.

Quick Steps
Setup and verify the ESP32.

Follow these in order.

  1. Power up: Plug in the ESP32 and wait 30-60 seconds.
  2. Connect to setup Wi-Fi: Connect your phone or laptop to WestTech Setup. If no page opens, browse to http://192.168.4.1.
  3. Enter Wi-Fi details: Select or type the 2.4 GHz Wi-Fi name, enter the password, then tap Save / Connect.
  4. Confirm success: The setup Wi-Fi should disappear. Check the router, ESPHome, or Home Assistant for the device. The web portal may show the WestTech ESP32 status page.
  5. Optional - upload final firmware: If installing default GP/MP firmware, open the device web page by IP and upload the correct ESPHome .bin / OTA .bin file. Do not unplug power during upload.
Internal verification checkpoint: If flashing completes and the WestTech web/setup page appears, the ESP32 passes basic flash/boot/web verification.
Recovery
If something fails.

Use the matching recovery step below.

No setup Wi-Fi

Wait 60 seconds, power-cycle once, try a different USB cable or power supply, then re-flash by USB if needed.

Portal does not open

Stay connected to WestTech Setup and manually open http://192.168.4.1. Temporarily disable mobile data if needed.

Wi-Fi will not join

Confirm 2.4 GHz Wi-Fi, re-check the case-sensitive password, and move closer to the router.

Firmware upload fails

Confirm you selected the correct .bin / OTA .bin file, retry once, then recover by USB if the device does not return.
