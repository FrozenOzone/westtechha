How to Choose
Start Simple If You Can
Shell or kit first • custom only when it makes sense

Most customers can start with a shell or a kit. If your project needs an ESP32 installed, custom programming, or a more tailored enclosure configuration, a custom build can be quoted separately.

  • Shell = enclosure only
  • Kit = enclosure plus mounting and closure accessories
  • Custom Build = hardware and programming by request
