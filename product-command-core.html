Family Description
The expanded family in the lineup

Command Core is the standard full-size option inside the Command family for larger indoor automation projects that need more internal room, OLED/LCD-ready support, power-planning space, and serviceable HSI-based mounting.

Why Command Core
A fuller platform with serviceability built in

Command is the larger WestTechHA platform for builds that need more room, better service access, and a cleaner path for display-ready layouts.

Full Setup

OLED / LCD-ready platform

Command is the full-size option in the product family, with room and layout support for display-ready projects such as OLED or LCD2004-style options.

Power Layout

Designed around larger builds

Command gives larger automation projects more room for wiring, power planning, and service access than the smaller Scout and Ranger families.

Serviceability

HSI system across the product line

The HSI-based serviceable mounting system is part of the WestTechHA product standard, making the enclosure easier to reopen and maintain.
