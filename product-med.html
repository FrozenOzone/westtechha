More room, more flexibility, still built as a real kit.

The Med kit is the middle size in the WestTechHA line. It gives customers more working room than Small while keeping the same product direction: enclosure, lid, installed hardware, magnets, and matched inserts included as part of the kit.

Why Med
Why this size exists

The Med kit gives customers a stronger middle-ground option: more interior room, more flexibility for board layout and supporting hardware, and a cleaner install path without having to jump to the biggest enclosure.

Best Fit

Projects needing more room

Best when Small feels too tight, you want more room for layout planning, or you want an enclosure that can better support a more feature-rich install path.
