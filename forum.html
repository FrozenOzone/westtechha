Community Rules

  • Be respectful and keep replies useful.
  • Do not post Wi-Fi passwords, full addresses, or private account details.
  • For safety-critical issues, include exact behavior and exact hardware details.
  • Post the working fix when a problem is solved.

Before You Post

These details make answers faster and better.

  • Panel type: GAP / SAP / MAP / other
  • Board type: ESP32-WROOM / ESP32-C6 / other
  • Network type: Wi-Fi / LAN8720 Ethernet
  • What changed
  • What you already tried
  • Any error text, logs, or screenshots
  • Firmware or config version, if known

Forum Flow

Simple and functional for now.

  • Use this page as the forum home and category launcher.
  • Use GitHub Discussions for live topics, replies, and searchable answers.
  • Use Support for structured help and product guidance.
  • When a fix works, post the final answer so the next person can find it.
