Known Questions
Common Themes
  • “Should I buy a shell or a kit?”
    Start with a shell if you already know your hardware and just need a cleaner enclosure. Step up to a kit if you want a more complete install package.
  • “Can I request a custom opening or layout?”
    Yes, but that may move the request into quote territory depending on how custom the build needs to be.
  • “Do you still do custom ESP32 builds?”
    Yes. Custom builds are still available, but they are now a request/quote path instead of the main public catalog.
